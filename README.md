# WhatsApp_Automation 🚀🚀
A WhatsApp AI bot for students. Handles text, voice, and image messages, fetches course materials from Moodle, searches the web for answers, and manages Google Calendar events (create, view, update) — all powered by n8n and multiple LLMs (Gemini, Openai, Groq).
